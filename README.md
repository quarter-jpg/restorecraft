# Restorecraft is a Minecraft datapack made from scratch for 26.3.

This datapack is for singleplayer use only and for use with the Archipelago Manual multiworld randomizer.
The player begins on a 250x250 superflat (barring some handmade structures) consisting of a layer of mycelium on top of bedrock. The goal of
the world is to sweep up the goal amount of mycelium and find the exit slips to "go home" afterwards. There are several other activities to do
around the world, such as fishing and trading, that send checks to the Multiworld, and there is a tad bit of lore to spice up the gameplay.

This datapack is still in a slightly early phase of building but is nevertheless in a well playable state. There are toggles for each sanity
and there are plans to add more in the future. Important links are down below.
